One word for your Wi-Fi: **Ghosting**. A judge model compares words two
at a time and the funniest, truest one wins the $2 reward and becomes the
sponsor's network name.

**The word** (8 characters):

> Ghosting

Why this word: it is the dating word for what home Wi-Fi actually does —
disappear mid-call, mid-show, mid-game, with no warning and no goodbye,
then drift back later like nothing happened. Everyone has been ghosted by
their router. It lands as a joke with no caption, it is true in a way
anyone with a dead zone recognises instantly, and it is a fresh angle
instead of the obvious "slow", "laggy" or "buffering".

`main.ts` (Node 22, standard library only) prints the word and writes the
exact same bytes to `/output/entry.txt`, the path the kit's gate scorer
reads. `entry.txt` holds the word exactly as submitted. The gate requires
1–20 characters, not only whitespace; this word is 8.

## Run it

```sh
node main.ts
```
